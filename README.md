# 智学网阅卷助手

<img src="assets/book-logo.png" alt="智学网阅卷助手标识" width="112">

由赛闲僧科技出版的 Windows 阅卷工具。本项目闭源，GitHub 仓库用于发布安装包和更新说明。

## 主要功能

- 支持语文、数学、英语、历史、物理、地理、化学、生物和政治九科，可导入试题与评分依据，匹配整题或小题。
- 支持本地 Ollama 和兼容的云端视觉模型，用于答卷识别、辅助评分与回评学习。
- 可分类归档典型案例、生成讲评 PPT，并导出阅卷记录、自学习资料及外部 AI 讲评课件制作包。

[下载安装程序及查看更新说明](https://github.com/saixs8/zhixue-grader-releases/releases/latest)

安装和运行需要设备授权。打开安装器并点击安装，复制设备码发给赛闲僧科技。收到授权 JSON 后导入。每份授权对应一台电脑。
